# Statement of Work: Islamic Lending Implementation for Bank Al-Noor [SAMPLE]
**Document Reference: SOW-2023-BAN-001 [SAMPLE]**

**Project Lead: Ahmed Khalil (ahmed.khalil@bankalnoor.ae, +971-4-555-0199)**  
**Vendor: Azentio Software Private Limited**

## 1. Project Scope & Objectives
The purpose of this Statement of Work is to deploy AzentioFinance v3.0 to automate consumer Murabaha financing and corporate Ijarah leasing for Bank Al-Noor in Dubai, UAE.

The implementation includes:
- Deployment of AzentioFinance v3.0 on Bank Al-Noor's private Kubernetes OpenShift cluster.
- Full integration with Temenos T24 core banking system using Azentio's pre-built REST connectors.
- Automated Tawarruq commodity execution connecting directly with Bursa Suq Al-Sila.
- Automated charity accounting module compliant with UAE Central Bank Sharia governance framework.

## 2. Project Timeline & Delivery Milestones
The project is scheduled for an 18-week timeline across four phases:
- Phase 1: Requirements validation and architecture blueprint (Weeks 1 to 4).
- Phase 2: Configuration, CBS adapter development, and SIT (Weeks 5 to 11).
- Phase 3: User Acceptance Testing (UAT) and Sharia Board Sign-Off (Weeks 12 to 15).
- Phase 4: Production cutover, data migration, and hypercare (Weeks 16 to 18).
