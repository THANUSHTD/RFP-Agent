# Past RFP Response: Riyadh Finance Company Lending RFP [SAMPLE]
**RFP Reference: RFP-2022-RIYADH-019 [SAMPLE]**  
**Bidder: Azentio Software**  
**Customer: Riyadh Finance Company**  
**Client Lead: Faisal Al-Otaibi (faisal.otaibi@riyadhfinance.sa)**

## Question 2.4: Core Banking System Integration Adapters
**Question**: Detail the supported methods for real-time integration with legacy core banking databases and transaction journals.  
**Response (Azentio)**: In AzentioFinance v2.1, integration is supported via asynchronous SOAP XML Web Services, JDBC database staging tables, and IBM MQ message queues. Real-time RESTful APIs and Kafka streaming require version 3.0.

## Question 7.5: Commercial License Fees [CONFIDENTIAL]
**Question**: Detail the total perpetual license fee for the lending platform.  
**Response (Azentio)**: Azentio quoted Riyadh Finance a software perpetual license fee of SAR 4,200,000 for up to 250 concurrent branch and call center users, with annual AMC priced at SAR 600,000.
